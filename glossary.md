# Glossary

How Fernway talks. Learn **account vs venue** first.

## Terms

### Account vs venue

- One **account** can have many **venues**.
- **Billing is per venue. Contracts are per account.**
- New hires mix these up constantly.
- See [company/pricing.md](company/pricing.md).

### Pay rules

The per-country break and overtime configuration, set during onboarding. See [processes/customer-onboarding.md](processes/customer-onboarding.md).

### The importer

The CSV staff-import tool. It fails on names with non-Latin characters and on Apple Numbers exports; see [runbooks/01-onboard-a-new-customer.md](runbooks/01-onboard-a-new-customer.md).

### T2L

Time to live: **contract signed → first schedule published**. Fernway's main onboarding metric.

### Ghost shift

A published shift nobody claimed. The single most common support complaint.

### Friday freeze

The no-deploys-on-Friday rule (team rule 5). See [processes/releases.md](processes/releases.md).

### Mara-check

A pricing exception that needs the CEO, Mara Voss. Anything below list price or the annual-prepay discount. See [company/pricing.md](company/pricing.md).
